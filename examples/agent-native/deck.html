deckforge / the agent model

From AI that rewrites files.To edits you can audit.

Typed slides an AI can edit safely, scoped to one slide or the whole deck, and undone in one step.

deckforge example deck Built from a brief by the Copilot skill

Open with the shift. Many AI slide tools either generate a whole deck in the cloud or rewrite a file that you
then have to re-read. deckforge takes another route: the agent edits typed slides through a small set of tools,
and every turn can be reviewed and undone.

Sources: deckforge docs, guide/agent-model and guide/why-deckforge (checked October 2026).

deckforge / agent-native decks03 / 08

Same geometry as the previous slide: only the labels change.

The drawer talks to a Copilot SDK session that runs on the user's existing GitHub Copilot sign-in, so there is
no new account or API key. A GitHub Copilot subscription is still required.

The boundary is 16 deck tools: four read tools (get_deck, list_templates, list_themes, list_assets) and twelve
that change the deck. With the "This slide" scope only seven slide tools are accepted, and only for the selected
slide id. `deckforge mcp` adds get_authoring_guide for external agents (17 tools).

Sources: src/server/deck-tools.js and guide/agent-model (checked October 2026).

deckforge / agent-native decks04 / 08

Walk left to right. Ask: the scope toggle decides what the agent may touch. Apply: the agent reads the deck,
then calls tools; each call is validated, and a refused call is flagged in the drawer. Review: the rail
highlights the changed slides and the turn summary lists the slides, slots and tool calls.

Then trace the feedback path: one click on "Undo these changes", or Cmd/Ctrl+Z, reverts the whole turn.

04 / The boundary

What the agent can never do

Enforced by the editor, not by the prompt.

  1. 01No shell, file or web access. Every other permission request is refused.
  2. 02No images from outside. Only files already in the deck's assets/ folder.
  3. 03No edits beyond its scope. This slide means one slide id, nothing else.
  4. 04No edits outside a turn. Changes are refused when no request is active.
  5. 05No remote access. The editor binds 127.0.0.1 behind a token and an Origin check.

The takeawayThe guarantees live in code you can read, not in instructions the model may ignore.

deckforge / agent-native decks05 / 08

Each point maps to a check in the code, not a line in the system prompt:
- the Copilot session only lists the deck tools and rejects every other permission request;
- a change that introduces an image outside assets/ is refused before it is applied;
- with the slide scope, other tools and other slide ids are refused;
- the drawer's tools refuse changes when no agent turn is active;
- the editor listens on 127.0.0.1, requires a per-run token and checks the Origin header on writes.

Sources: guide/agent-model "What the agent can never do" and reference/security (checked October 2026).

05 / Pick the right tool

When deckforge fits, and when it doesn't

Pick deckforge

You want an AI to edit, but every change must be typed, scoped and reversible, in a source that diffs well.

Pick something else

Code-heavy talks, free-form layouts, one source for many formats, or a design-first deck from a prompt.

deckforge / agent-native decks07 / 08

Be fair. Slidev fits code-heavy talks and custom components. Markdown frameworks and PowerPoint give more freedom
for one-off layouts. Quarto renders one source to many formats. Hosted generators such as Gamma and Beautiful.ai
are built for design-first decks from a prompt.

Every claim here is sourced on deckforge.vuptime.io/guide/why-deckforge (checked October 2026).
